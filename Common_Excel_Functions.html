Excel for Business Managers: Formula & Function Cheat Sheet

This reference focuses on the Excel functions and tools used in this course. Use it to remember what each function does, how the formula is written, and when it is most useful.

FunctionExampleWhat It DoesBest Used For
SUM=SUM(B2:B10)Adds all numbers in the selected range.Total sales, expenses, units, hours, or revenue.
AVERAGE=AVERAGE(B2:B10)Calculates the arithmetic mean.Average sales, salary, rating, cost, or performance.
MIN=MIN(B2:B10)Returns the smallest value.Lowest cost, sales, time, or score.
MAX=MAX(B2:B10)Returns the largest value.Highest sales, salary, profit, or score.
COUNT=COUNT(B2:B10)Counts cells containing numbers.Counting numeric observations.
COUNTA=COUNTA(A2:A10)Counts nonblank cells.Counting employees, products, customers, or records.

Cell references determine what happens when you copy a formula.

TypeExampleWhat Happens When Copied?
Relative=B2*C2Both references change.
Absolute=B2*$F$1F1 stays fixed.
Mixed=$B2*C$1Either the row or the column remains fixed.
Example: If F1 contains an 8.25% tax rate, use =B2*$F$1 so every copied formula continues to use the same tax-rate cell.

IF

=IF(C2>=100000,"Target Met","Below Target")

Best for: Classifying performance, identifying bonus eligibility, flagging values above or below a threshold, and creating business categories.

AND

=AND(B2>=100000,C2>=0.20)

Returns TRUE only when all conditions are true.

OR

=OR(B2="Texas",B2="Louisiana")

Returns TRUE when at least one condition is true.

IF + AND

=IF(AND(B2>=100000,C2>=0.20),"Bonus","No Bonus")

Best for: Business rules that require several conditions to be satisfied at the same time.

FunctionExampleBest Used For
SUMIF=SUMIF(A2:A100,"Houston",B2:B100)Total sales by region, expenses by department, revenue by product.
COUNTIF=COUNTIF(C2:C100,"Yes")Counting employees who completed training, late orders, or customers in a category.
AVERAGEIF=AVERAGEIF(A2:A100,"Sales",B2:B100)Average salary by department, sales by region, or ratings by group.

VLOOKUP

=VLOOKUP(A2,$F$2:$H$100,3,FALSE)

Searches for the value in A2 in the first column of the lookup table and returns a corresponding value from another column.

Best for: Finding product prices, employee departments, customer information, or other values associated with an ID.

Tip: Use FALSE when you need an exact match.

HLOOKUP

=HLOOKUP(B1,$B$10:$G$12,3,FALSE)

Works like VLOOKUP, but searches horizontally across a row.

IFERROR

=IFERROR(VLOOKUP(A2,$F$2:$H$100,3,FALSE),"Not Found")

Replaces an Excel error with a message or value you choose.

Best for: Cleaning up lookup results and handling missing data.

FunctionExampleWhat It Does
CONCAT=CONCAT(A2," ",B2)Combines text, such as first and last names.
LEFT=LEFT(A2,3)Returns the first three characters.
RIGHT=RIGHT(A2,4)Returns the last four characters.
LEN=LEN(A2)Counts the number of characters in a cell.
TRIM=TRIM(A2)Removes unnecessary spaces from text.
FunctionExampleBest Used For
ROUND=ROUND(B2,2)Rounding currency, percentages, or calculated values.
ROUNDUP=ROUNDUP(B2,0)Always rounding upward.
ROUNDDOWN=ROUNDDOWN(B2,0)Always rounding downward.
ErrorUsually Means
#####The column is too narrow to display the value.
#DIV/0!The formula is attempting to divide by zero.
#N/AExcel cannot find the requested value.
#NAME?Excel does not recognize something in the formula.
#REF!The formula contains an invalid cell reference.
#VALUE!The formula is using the wrong type of data.
  1. Does the formula begin with =?
  2. Are all parentheses opened and closed correctly?
  3. Are text criteria inside quotation marks?
  4. Are the correct cells or ranges selected?
  5. Should any references contain $ signs?
  6. Are numbers stored as numbers rather than text?
  7. For VLOOKUP, is the lookup value in the first column of the lookup range?
  8. If you need an exact VLOOKUP match, did you use FALSE?
  9. What error message is Excel displaying?
