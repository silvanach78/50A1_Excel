Excel for Business Managers

Spreadsheet Formatting and Presentation

Formatting worksheets for clarity, readability, and managerial interpretation.

How to use this reading: Use the navigation menu to move directly to any topic you want to review. The sections are organized in the same sequence as the Module 3 skills.

Formatting is more than decoration. In a well-designed worksheet, formatting helps readers understand the structure of the information, distinguish categories, identify important values, and interpret numerical data correctly.

This module uses a monthly budget as a practical example. The budget is organized around three major categories: income, expenses, and savings. As the worksheet is built, formatting tools are applied to make the information easier to read and use.

Building on Earlier Skills

Several previously introduced Excel skills are used again, including renaming worksheets, SUM(), AutoFit, arithmetic formulas, the fill handle, and cell references.

1. Font Formatting

Font formatting changes the appearance of text and numerical information in a cell. Excel provides familiar formatting controls for font family, size, emphasis, and color.

Common Font Formatting Options

  • Font family
  • Font size
  • Bold
  • Italic
  • Underline
  • Font color

Formatting a Worksheet Title

A worksheet title such as July 2025 Monthly Budget can be formatted differently from the rest of the worksheet so that it is immediately recognizable as the document title.

  1. Select the cell containing the title.
  2. Go to the Home tab.
  3. Select the desired font family.
  4. Adjust the font size as needed.
  5. Apply bold, font color, or other emphasis when appropriate.
Formatting Should Have a Purpose
A different font or color can help establish hierarchy, but excessive variation can make a worksheet harder to read. Use formatting to clarify structure.

2. Background Color of a Cell

Cell background color, also called fill color, can help visually separate sections of a worksheet.

In a monthly budget, different colors can be assigned to major categories:

Budget Category Example Color Purpose
Income Green Visually identifies money coming in.
Expenses Orange Separates spending from other categories.
Savings Blue Distinguishes money allocated to savings.
Left Over Yellow Draws attention to the amount remaining after planned spending and saving.

Apply a Background Color

  1. Select the cell or range of cells.
  2. Go to the Home tab.
  3. Select the Fill Color command.
  4. Choose a color that supports the meaning of the worksheet.
Use color meaningfully: Color can create visual categories, but it should help the reader understand the worksheet rather than simply make it more colorful.

3. Borders

When background colors are added to a range of cells, the worksheet gridlines may become less visually distinct. Borders can restore structure and make individual cells easier to identify.

Apply Borders

  1. Select the range of cells.
  2. Go to the Home tab.
  3. Open the Borders menu.
  4. Select All Borders when you want each cell in the range outlined.
Example
If the Income section has a green background, applying All Borders creates clear divisions between the individual income entries.

Borders and Worksheet Organization

Borders are especially useful when a worksheet contains several categories or when colored cells would otherwise blend together.

4. Currency

Financial values should usually be displayed using an appropriate number format. Currency formatting helps readers immediately recognize that a value represents money.

Apply Currency Formatting

  1. Select the cells containing monetary values.
  2. Go to the Home tab.
  3. Select the appropriate Currency or Accounting format.

For example, a value stored as:

4000

may be displayed as:

$4,000.00
Formatting Does Not Change the Underlying Number
Currency formatting changes how the value appears. Excel still uses the original numerical value in calculations.

Using SUM() for Budget Totals

Each budget category can include a total row calculated with SUM().

=SUM(B5:B17)

As new income, expense, or savings values are entered within the summed range, the total updates automatically.

Calculating the Amount Left Over

The amount remaining after expenses and savings can be calculated with a basic subtraction formula:

=Total Income - Total Expenses - Total Savings

Using cell references, the formula might look similar to:

=B18-E18-H18
Budgeting principle: A worksheet can be designed so that every dollar has an intended purpose. As planned expenses or savings change, the amount left over updates automatically.

5. Percentages

Percentage formatting is useful when you want to express a value as a proportion of a larger total.

Percentage of Total Income

Suppose one income source is $4,000 and total monthly income is $7,000. The proportion of total income can be calculated as:

=4000/7000

Excel may initially display the result as a decimal, such as 0.5714. Applying percentage formatting changes the display to approximately 57.14%.

Apply Percentage Formatting

  1. Select the cell containing the decimal result.
  2. Go to the Home tab.
  3. Select the Percent Style (%) command.
  4. Increase or decrease decimal places as needed.

Common-Size or Vertical Analysis

A common-size analysis expresses individual line items as a percentage of a common denominator. In a budget, useful comparisons include:

  • Each income source as a percentage of total income
  • Each expense as a percentage of total expenses
  • Each expense as a percentage of total income
  • Each savings contribution as a percentage of total income
Example: Expense as a Percentage of Total Income
If monthly rent is $1,800 and total income is $7,000:
=1800/7000
After applying percentage formatting, rent represents approximately 25.71% of total income.

Absolute Cell References

When a formula is copied down a column, Excel normally changes both the numerator and denominator references. Sometimes the denominator must remain fixed.

For example, if B18 contains total income, this formula:

=B5/B18

will change both references if it is copied downward. To keep total income fixed, convert B18 to an absolute reference:

=B5/$B$18

On many keyboards, pressing F4 while the reference is selected cycles through relative and absolute reference options.

Why the Dollar Signs Matter
The dollar signs in $B$18 lock both the column and row. When the formula is filled downward, the numerator can change while the denominator remains fixed.

Using the Fill Handle with an Absolute Reference

Once the denominator has been made absolute, the formula can be copied down the column with the fill handle. Each row will use a different numerator while continuing to divide by the same total.

Formula Meaning
=B5/$B$18 First income item divided by total income.
=B6/$B$18 Second income item divided by the same total income.
=E5/$E$18 First expense divided by total expenses.
=E5/$B$18 First expense divided by total income.

6. Merge and Center

Merge & Center combines several adjacent cells into one larger cell and centers the contents across the merged area.

This can be useful for a worksheet title that applies to several columns.

Merge and Center a Title

  1. Select the cell containing the title and the adjacent cells the title should span.
  2. Go to the Home tab.
  3. Select Merge & Center.

The selected cells become one larger cell, and the title is centered within it.

Undo Merge and Center

Select the merged cell and choose Merge & Center again to return the cells to their previous structure.

Use Merge & Center Selectively
It works well for titles and presentation areas, but it should not be used unnecessarily inside datasets where individual cell structure is important.

7. Conditional Formatting

Conditional formatting automatically changes the appearance of cells when specified conditions are met.

In a budget, conditional formatting can help identify the largest expense without requiring the reader to manually compare every value.

Highlight the Largest Expense

  1. Select the expense values.
  2. Go to Home > Conditional Formatting.
  3. Open Top/Bottom Rules.
  4. Select the option that identifies the top value or top item.
  5. Choose a formatting style, such as red text or a red fill.
  6. Apply the rule.

Conditional Formatting Updates Automatically

Conditional formatting remains connected to the values in the selected range. If the data changes and another expense becomes the largest value, Excel can automatically move the formatting to the new largest expense.

Example
If rent is initially the largest expense, it may be highlighted. If a student-loan payment is later increased above the rent amount, the conditional formatting can automatically identify the student-loan payment as the new largest expense.
Managerial value: Conditional formatting reduces the time required to scan a worksheet and can direct attention to values that require review or action.

  • Use background colors to organize worksheet sections.
  • Apply borders to improve visual structure.
  • Format numerical values as currency.
  • Format decimal values as percentages.
  • Increase or decrease displayed decimal places.
  • Use SUM() to calculate category totals.
  • Create a subtraction formula to calculate a remaining balance.
  • Calculate line items as percentages of a total.
  • Explain the purpose of a common-size or vertical analysis.
  • Use an absolute cell reference such as $B$18.
  • Use F4 to create or cycle through absolute reference options.
  • Copy percentage formulas using the fill handle.
  • Use Merge & Center for worksheet titles.
  • Apply conditional formatting to identify important values.
  • Explain how conditional formatting responds when underlying values change.
