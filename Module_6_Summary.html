Data Analysis with PivotTables

Summarizing large datasets with PivotTables and communicating the results with PivotCharts.

How to use this reading: Use the navigation menu to move directly to any topic you want to review. This module focuses on turning a large, detailed dataset into useful managerial summaries.

PivotTables are among Excel's most powerful tools for exploring large datasets. Rather than manually searching through thousands of rows, you can organize, filter, compare, and summarize data by dragging fields into different areas of a PivotTable.

This module uses publicly available hospital patient-experience data as an example. The dataset contains hundreds of thousands of rows, making it a useful demonstration of why PivotTables are valuable when working with real-world data.

1. Working with Real-World Data

Real-world datasets are often much larger and more complex than the small examples used for practice. A single dataset may contain thousands of records, many variables, and multiple related files.

The hospital dataset used in this module comes from the U.S. Centers for Medicare & Medicaid Services (CMS) Provider Data Catalog. The downloaded archive contains multiple CSV files and a data dictionary.

The image below shows where to locate the latest dataset: Provider Data Catalog > Hospitals > View Data Archives.

CSV Files

CSV stands for Comma-Separated Values. CSV files store tabular data in a simple text-based format and can be opened directly in Excel.

Large Datasets Require Different Tools
A dataset with hundreds of thousands of rows is not practical to analyze by manually scrolling, selecting, or copying individual records. PivotTables allow you to summarize the data without rearranging the raw file.

Fields in the Hospital Dataset

Examples of fields include:

  • Facility ID
  • Facility Name
  • Address
  • City/Town
  • State
  • ZIP Code
  • County
  • Telephone Number
  • HCAHPS Question
  • HCAHPS Answer Percent
  • HCAHPS Linear Mean Value

2. Understanding the Data Dictionary

Large datasets are often accompanied by a data dictionary. A data dictionary explains the fields and measures contained in the dataset.

Before analyzing an unfamiliar dataset, review the data dictionary to understand what each variable means and how the measures are defined.

HCAHPS Patient Experience Measures

The analysis in this module focuses on HCAHPS patient-experience data. HCAHPS includes measures related to areas such as:

  • Nurse communication
  • Doctor communication
  • Staff responsiveness
  • Communication about medicines
  • Overall patient experience

Answer Percent vs. Linear Mean Value

Some HCAHPS questions are represented by several response percentages. For example, nurse communication may contain separate percentages for patients who report that nurses always, usually, or sometimes/never communicated well.

The HCAHPS Linear Mean Value summarizes the distribution of responses into a single score on a 0-to-100 scale. This makes it useful for comparing hospitals on one measure.

When in doubt, return to the raw data and the data dictionary. Understanding what a field actually measures is essential before summarizing or interpreting it.

3. Creating a PivotTable

A PivotTable summarizes a large dataset without changing the underlying raw data. Excel can automatically identify the full range when a cell inside the dataset is selected.

Create a PivotTable

  1. Select a cell inside the dataset.
  2. Go to the Insert tab.
  3. Select PivotTable.
  4. Confirm that Excel identified the correct table or range.
  5. Choose New Worksheet as the location.
  6. Select OK.

Excel opens a new worksheet containing an empty PivotTable and a list of available fields.

Why a New Worksheet?
Placing the PivotTable on a separate worksheet keeps the raw data intact and gives the analysis its own workspace.

4. Building the PivotTable

PivotTables are constructed by dragging fields into four areas: Rows, Columns, Values, and Filters.

PivotTable Area Purpose Example
Rows Creates categories listed vertically. Facility Name
Columns Creates categories displayed across the top. HCAHPS Question
Values Contains the numerical measure being summarized. HCAHPS Linear Mean Value
Filters Limits the analysis to selected records. State and City/Town

Rows: Facility Name

Dragging Facility Name into Rows creates one row for each facility represented in the dataset.

Columns: HCAHPS Question

Dragging HCAHPS Question into Columns creates a separate column for each selected patient-experience measure.

For this analysis, useful measures include:

  • Doctor Communication Linear Mean Score
  • Nurse Communication Linear Mean Score

Values: HCAHPS Linear Mean Value

Drag HCAHPS Linear Mean Value into Values to place the numerical patient-experience scores inside the table.

5. Filtering PivotTable Data

Filters make it possible to focus a PivotTable on a relevant subset of a much larger dataset.

Filter by State

Drag State into the Filters area. Use the filter drop-down to select Texas.

Filter by City/Town

Drag City/Town into the Filters area and select Houston. The PivotTable now focuses on hospitals in Houston, Texas rather than comparing every hospital in the country.

Managerial relevance: A comparison is more useful when the records are meaningfully comparable. Filtering by geography can narrow a national dataset to a relevant local market.

Filtering the Column Field

A field placed in Columns can also be filtered. If HCAHPS Question contains many measures, deselect the measures that are not relevant and retain only those you want to compare.

6. Summarizing Values

When a numerical field is added to Values, Excel may initially summarize it using Count. The summary calculation can be changed using Value Field Settings.

Change Count to Average

  1. Open the menu for the field in the Values area.
  2. Select Value Field Settings.
  3. Choose Average.
  4. Select OK.

Using Average is appropriate when comparing the HCAHPS Linear Mean Value for selected measures.

Check the Summary Function
Do not assume Excel selected the correct calculation automatically. Always confirm whether the Values area is using Count, Sum, Average, Max, or another appropriate summary.

Missing or Unreported Values

Some facilities may not report a particular measure. This can occur because certain hospital types are not required to report every HCAHPS variable. Missing values should not automatically be treated as poor performance.

7. Formatting a PivotTable

Conditional formatting can make a PivotTable easier to interpret by visually distinguishing higher and lower scores.

Apply Conditional Formatting One Measure at a Time

When the PivotTable contains multiple measures, apply conditional formatting to each measure separately.

Do Not Combine Different Measures in One Color Scale
Selecting several different variables at once can create a misleading color scale because Excel evaluates the entire selected range together.

Use a Color Scale

  1. Select the values for one measure, such as Doctor Communication.
  2. Go to Home > Conditional Formatting.
  3. Select Color Scales.
  4. Choose a scale in which higher values are represented as better performance.
  5. Repeat the process separately for the next measure.

For communication scores, a higher value indicates better performance, so a green-to-red scale can be interpreted with green as higher and red as lower.

8. Creating a PivotChart

A PivotChart provides a visual representation of summarized PivotTable-style data while preserving the ability to filter and reorganize fields.

Create a PivotChart

  1. Select a cell inside the raw dataset.
  2. Go to the Insert tab.
  3. Select PivotChart.
  4. Confirm the data range.
  5. Select OK.

PivotChart Areas

PivotCharts use areas that closely correspond to the PivotTable structure:

PivotChart Area Example Field
Axis Facility Name
Legend HCAHPS Question
Values HCAHPS Linear Mean Value
Filters State and City/Town

The same filters used in the PivotTable can be applied to the PivotChart, such as Texas for State and Houston for City/Town.

9. Formatting a PivotChart

PivotCharts can be adjusted to make patterns easier to see and to improve the usefulness of the visualization.

Adjusting the Vertical Axis Bounds

When all scores are clustered near the upper end of a 0-to-100 scale, the differences between facilities may be difficult to see.

The vertical axis bounds can be adjusted by selecting the axis and changing the minimum bound. For example, changing the lower bound from 0 to 75 makes variation among high scores more visible.

Interpret Axis Changes Carefully
Changing the axis range can make small differences appear more noticeable. Use the adjustment to support analysis, but interpret the visual scale carefully.

Switch Row and Column Orientation

The Switch Row/Column command changes how categories and series are arranged in the chart. This can make a chart easier to read, depending on the number of hospitals and measures being compared.

Change the Chart Type

A PivotChart is not limited to one chart format. You can change the chart type when another visual form better communicates the data.

Available choices may include:

  • Column or bar charts
  • Line charts
  • Pie charts
  • Other Excel chart types
Choose the chart type based on the analytical question. A chart should make the comparison easier to understand rather than simply provide a visual version of the data.
