Excel for Business Managers

Excel Fundamentals

A companion reading for the introductory lecture on navigating Excel, organizing data, formatting worksheets, using tables, and performing basic calculations.

How to use this reading: Use the navigation menu to move directly to any topic you want to review. This document follows the same topic order as the accompanying video lecture.

Microsoft Excel is much more than a place to enter numbers. It is a business tool for organizing information, performing calculations, identifying patterns, summarizing data, and supporting managerial decision-making.

You do not need to memorize every command presented here. The goal is to become comfortable navigating Excel and to understand how its tools can help you work more efficiently.

1. Cells, Columns, and Rows

An Excel file is called a workbook. A workbook can contain one or more worksheets.

Worksheets are organized into columns, rows, and cells.

Excel Element What It Does How It Is Identified
Column Runs vertically, from top to bottom. Letters: A, B, C, D...
Row Runs horizontally, from left to right. Numbers: 1, 2, 3, 4...
Cell The intersection of a column and a row. Column letter + row number
Example
The cell located in Column D and Row 5 is called D5.

The Name Box

The Name Box, located near the upper-left area of Excel, displays the reference of the currently selected cell. If you click D5, for example, the Name Box displays D5.

The Formula Bar

The Formula Bar shows the actual contents of the selected cell. Those contents may be text, a number, a date, or a formula.

2. Zoom

The Zoom control is normally located in the lower-right corner of the Excel window.

Zooming changes only how large the worksheet appears on your screen. It does not change your data or the actual size of the cells.

Manager Tip
Zoom in when you need to examine a small section of a worksheet. Zoom out when you are working with a large dataset and need a broader view.

3. Entering Data

To enter data, select a cell and begin typing. Press Enter when you are finished.

In the lecture example, we create a small dataset containing monthly cookie sales.

Column Headers

The first row of a dataset commonly contains headers. Headers identify what each column represents.

Date Cookie Sales
Jan-231300
Feb-234000
Mar-235000

How Excel Stores Dates

Excel may display a date differently from the way you originally entered it. For example, you might enter January 2023 and see Jan-23 displayed in the cell. The Formula Bar may show a complete date such as January 1, 2023.

Remember
What you see in a cell is not always exactly the same as the value Excel stores. The Formula Bar can help you see the underlying value.

4. Flash Fill and AutoFill

Excel can recognize patterns and use them to help you enter data more efficiently. Two useful features are AutoFill and Flash Fill.

Important distinction: Although both features recognize patterns, AutoFill and Flash Fill perform different tasks.

AutoFill and the Fill Handle

AutoFill extends an existing value, sequence, or formula. It is commonly used for dates, months, days of the week, numbers, and formulas.

The fill handle is the small square that appears in the lower-right corner of a selected cell.

Example: Filling Months

  1. Enter January in a cell.
  2. Select the cell.
  3. Point to the fill handle in the lower-right corner.
  4. Click and drag downward.
  5. Excel continues the sequence with February, March, April, and the remaining months.

AutoFill can recognize sequences such as:

  • January, February, March...
  • Sunday, Monday, Tuesday...
  • Sequential dates
  • Number patterns
  • Repeated or copied formulas

Flash Fill

Flash Fill recognizes a pattern that you establish by transforming existing data and uses that pattern to complete the remaining values. Flash Fill is particularly useful when working with text.

Example: Combining First and Last Names

Suppose Column A contains first names and Column B contains last names. You want Column C to contain each person's full name.

  1. In the first available cell in Column C, type the first person's full name exactly as you want it to appear and press Enter.
  2. Begin typing the next person's full name in the next row.
  3. Excel may recognize the pattern and display a preview of the remaining names.
  4. If the preview is correct, press Enter to accept it.
When Flash Fill Is Useful
Flash Fill can help you combine names, separate text, extract parts of codes or identifiers, and reformat text based on a pattern.

5. Formatting Cells

Excel allows you to change how information appears without changing the underlying value stored in the cell.

Formatting Numbers as Currency

If a worksheet contains sales data, displaying the values as currency makes the information easier to interpret.

For example, Excel may store the value:

79300

but display it as:

$79,300.00

Apply Currency Formatting

  1. Select the cells containing monetary values.
  2. Go to the Home tab.
  3. Select the appropriate Currency or Accounting Number Format command in the Number group.
Formatting Does Not Change the Value
Number formatting changes how Excel displays a value. It does not change the value used in calculations.

6. AutoFit Contents

Sometimes the contents of a cell are wider than the column containing them. Excel's AutoFit feature automatically adjusts the width of a column to fit its contents.

  1. Move your pointer to the boundary between two column headings.
  2. When the resize pointer appears, double-click the boundary.
  3. Excel automatically adjusts the column width.

AutoFit Multiple Columns

If several columns need to be resized, select all of the relevant columns first and then use AutoFit. You can also select the entire worksheet and AutoFit all columns based on their contents.

Manager Tip
AutoFit is a quick way to improve readability before sharing a worksheet with someone else.

7. Hide and Unhide Columns

Sometimes a worksheet contains useful information that does not need to be visible all the time. Instead of deleting that information, you can temporarily hide the column.

Hide a Column

  1. Select the column.
  2. Right-click the selected column.
  3. Choose Hide.

Unhide a Column

  1. Select the columns on both sides of the hidden column.
  2. Right-click the selection.
  3. Choose Unhide.
Hide Is Not Delete
Hiding a column leaves the data in the workbook. Deleting a column removes the data.

8. Moving Columns and Cells

You can move cells or entire columns to reorganize a worksheet.

In the lecture example, the worksheet was initially organized as:

Cookie Sales | Date

It was reorganized as:

Date | Cookie Sales

This arrangement provides the context first and the corresponding numerical value second.

Selecting an Entire Column

Click the letter at the top of the column to select the entire column. Once selected, the column can be moved to a different location in the worksheet.

Manager Tip
Think about how someone else will read your worksheet. Good Excel design is not only about getting the calculation right. The information should also be easy to understand.

9. Insert Table

An Excel Table is more than a group of formatted cells. Converting a range into a Table adds tools that make organizing, sorting, filtering, and expanding data easier.

Create an Excel Table

  1. Select the dataset.
  2. Go to the Insert tab.
  3. Select Table.
  4. Verify that Excel identified the correct data range.
  5. If the first row contains headers, select My table has headers.
  6. Select OK.

Sorting and Filtering

Once the data has been converted to a Table, drop-down controls appear in the header row. These controls allow you to:

  • Sort data
  • Filter values
  • Display selected categories
  • Focus on particular dates, months, years, or other values
Business Example
If your table contains several years of monthly sales data, you could filter the Date column to display only one year without deleting any of the other records.

10. Insert Columns and Rows

You can insert new rows or columns when additional data needs to be added to an existing worksheet.

Insert a Row

In the lecture example, the dataset contains January through November, followed by a Total row. December needs to be inserted before the total.

  1. Select the row containing the current total.
  2. Right-click the row number.
  3. Choose Insert.
  4. Enter the December information in the new row.

Insert a Column

Columns can be inserted in a similar way when you need to add another field or variable to the dataset.

  1. Select the column immediately to the right of where the new column should appear.
  2. Right-click the column heading.
  3. Select Insert.
Why This Matters
A properly constructed worksheet can often adjust formulas automatically when new rows or data are inserted.

11. SUM()

The SUM function adds numerical values.

Basic Syntax

=SUM(B2:B12)

In this formula:

  • = tells Excel that a formula follows.
  • SUM identifies the function.
  • B2:B12 identifies the range of cells to be added.

Creating a SUM Formula

  1. Select the cell where the total should appear.
  2. Type =SUM(.
  3. Select the cells containing the values you want to add.
  4. Type the closing parenthesis ).
  5. Press Enter.
Example

If monthly sales are stored in B2 through B12:

=SUM(B2:B12)

Excel adds every numerical value from B2 through B12.

Using the Status Bar to Check Your Work

When you select several numerical cells, Excel's Status Bar can display quick calculations for those cells.

Depending on your settings, the Status Bar may display:

  • Average
  • Count
  • Numerical Count
  • Minimum
  • Maximum
  • Sum
Quick Check
The Status Bar is useful for checking a calculation without creating another formula in the worksheet.

Let Excel Do the Work

A key principle for this course: When Excel provides a function or formula for a calculation, use it. Avoid calculating values separately with a phone or calculator and then typing the result into Excel. Formulas allow the worksheet to respond when the underlying data changes.

12. Basic Math Formulas

Excel can perform standard arithmetic directly within a cell. Every formula begins with an equal sign.

Operation Symbol Example
Addition + =B2+B3
Subtraction - =B2-B3
Multiplication * =B2*B3
Division / =B2/B3

Example: First-Quarter Sales

If January, February, and March sales are stored in B2, B3, and B4, one way to calculate Q1 sales is:

=B2+B3+B4

You could also use:

=SUM(B2:B4)

When adding a range of cells, SUM is often easier to read and manage.

The AVERAGE Function

The AVERAGE function calculates the arithmetic mean of a group of numerical values.

=AVERAGE(B2:B4)

If B2 through B4 contain January, February, and March sales, this formula calculates the average monthly sales for Q1.

  1. Select the cell where the average should appear.
  2. Type =AVERAGE(.
  3. Select the range of values.
  4. Close the parenthesis.
  5. Press Enter.
