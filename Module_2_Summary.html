1. Renaming Worksheets

Recall that an Excel file is a workbook, and a workbook can contain multiple worksheets. By default, Excel may label worksheets with names such as Sheet1, Sheet2, and Sheet3.

Renaming worksheets makes a workbook easier to understand and navigate, especially when each sheet represents a different period, department, product, or type of analysis.

Rename a Worksheet

  1. Locate the worksheet tab at the bottom of the workbook.
  2. Right-click the worksheet tab.
  3. Select Rename.
  4. Type the new worksheet name.
  5. Press Enter.
Example
A worksheet could be renamed May 2024, while another worksheet could be renamed June 2024.

Creating Additional Worksheets

You can also that a workbook can contain multiple sheets. Additional sheets can be created and then renamed to reflect the information stored in each worksheet.

Generating Sample Data with RANDBETWEEN()

To quickly create sample car-sales data, this reading uses Excel's RANDBETWEEN function.

=RANDBETWEEN(0,500000)

In this example, Excel generates a random whole number between 0 and 500,000.

  • The first argument is the bottom, or minimum possible value.
  • The second argument is the top, or maximum possible value.
Random Values Recalculate
random values may change whenever the worksheet recalculates or is edited. Therefore, your generated values may not match the values shown in the worksheet.

RAND() vs. RANDBETWEEN()

Excel also includes RAND(). RAND generates a random decimal value between 0 and 1, while RANDBETWEEN allows you to specify a lower and upper bound.

Function Purpose Example
RAND() Generates a random decimal value between 0 and 1. =RAND()
RANDBETWEEN() Generates a random whole number between specified limits. =RANDBETWEEN(0,500000)

Formatting Sales as Currency

After the sample values are generated, this reading formats the sales values as dollars so they are easier to interpret.

SUM Syntax

=SUM(B2:B41)

The exact cell range depends on where your data is located. The function adds all numerical values in the selected range.

  1. Select the cell where the total should appear.
  2. Type =SUM(.
  3. Select the full range of sales values.
  4. Type the closing parenthesis ).
  5. Press Enter.

3. MIN()

The MIN function returns the smallest numerical value in a selected range.

=MIN(B2:B41)

MIN identifies the lowest monthly car-sales amount in the dataset.

  1. Select the cell where the minimum should appear.
  2. Type =MIN(.
  3. Select the range of numerical values.
  4. Close the parenthesis.
  5. Press Enter.

4. MAX()

The MAX function returns the largest numerical value in a selected range.

=MAX(B2:B41)

MAX identifies the highest monthly car-sales amount in the dataset.

5. AVERAGE()

The AVERAGE function calculates the arithmetic mean of a group of numerical values.

=AVERAGE(B2:B41)

AVERAGE calculates the average monthly car-sales amount for the dataset.

Interpret the Result
The average summarizes the center of the dataset, but it does not tell you which employee achieved that exact value.

6. COUNT()

The COUNT function counts the number of cells in a range that contain numerical values.

=COUNT(B2:B41)

In this example, COUNT is used on the car-sales values and returns the number of numerical observations in the selected range.

What COUNT Counts
COUNT counts cells containing numbers. In this reading's sales dataset, that result corresponds to the number of employee sales observations.

7. AutoSum

AutoSum provides a quick way to insert a SUM formula without typing the function manually.

AutoSum is accessed from the Home tab using the summation symbol Σ.

  1. Select the cell where the total should appear.
  2. Go to the Home tab.
  3. Select the AutoSum (Σ) command.
  4. Excel proposes a range of nearby numerical cells.
  5. Verify that the selected range is correct.
  6. Press Enter to accept the formula.
Excel recognizes nearby data: In this example, AutoSum automatically identifies the sales values directly above the total cell and proposes them as the range to sum.

AutoSum and SUM Produce the Same Calculation

AutoSum is simply a faster way to create a SUM formula. The resulting formula can produce the same total as typing SUM manually.

8. Moving and Copying Data

Excel allows you to copy or reposition cells, formulas, labels, and ranges within a worksheet.

Copying Data

standard copy-and-paste commands work in Excel in much the same way they work in other applications.

Moving a Selected Range

You can also selecting a block containing labels and calculated formulas and dragging the entire selection to another location in the worksheet.

Watch for Narrow Columns
If you move a numerical value into a column that is too narrow to display it, Excel may show a series of hash symbols such as #####. This does not mean the value is wrong. The column simply needs to be widened.

AutoFit After Moving Data

To correct a column that is too narrow, move to the right edge of the column heading and double-click the boundary. Excel will AutoFit the column to its contents.

Bonus: Conditional Formatting

Conditional Formatting allows Excel to change the appearance of cells when specified conditions are met.

conditional formatting is introduced as a preview of work that will be developed further in the following week.

Why Use Conditional Formatting?

A long list of numerical values can be difficult to interpret quickly. Conditional formatting can make important values stand out so that decision makers can identify patterns or exceptions more efficiently.

Example
Suppose the car-sales dataset contains 40 employees. Conditional formatting can make the top 10% of performers appear in green and the bottom 10% appear in red.

Preprogrammed Conditional Formatting Rules

Excel includes several types of built-in rules available from the Home > Conditional Formatting menu:

  • Greater Than
  • Less Than
  • Between
  • Equal To
  • Top/Bottom Rules
  • Top 10 Items
  • Top 10%
  • Bottom 10%
  • Above Average
  • Below Average
  • Color Scales

Highlighting the Top 10%

  1. Select the car-sales values.
  2. Go to Home > Conditional Formatting.
  3. Select Top/Bottom Rules.
  4. Select Top 10%.
  5. Choose a green fill with dark green text.
  6. Apply the rule.

Highlighting the Bottom 10%

  1. Keep the same sales range selected.
  2. Return to Conditional Formatting.
  3. Select Top/Bottom Rules.
  4. Select Bottom 10%.
  5. Apply a red formatting option.
Managerial use: The lecture emphasizes that formatting should make information easier to interpret quickly. In this example, a manager can immediately identify the strongest and weakest performers without scanning every number individually.

The Percentage Can Be Customized

the rule does not have to use 10%. Depending on the purpose of the analysis, a different percentage, such as the top and bottom 20%, could be more appropriate.
