Excel for Business Managers

Data Organization and List Management

Sorting lists, identifying duplicate records, querying structured data, and calculating summaries that respond to filters.

How to use this reading: Use the navigation menu to move directly to any topic you want to review. The sections are organized in the same sequence as the Module 5 skills.

Business datasets often contain many records and many variables. As a list grows, it becomes increasingly important to organize the data systematically rather than relying on visual inspection.

This module uses a fictional employee database with fields such as Last Name, First Name, Department, City, and Salary. The same tools can be applied to much larger datasets containing additional fields such as addresses, phone numbers, email addresses, or other business information.

Understanding a List or Database

In a structured list, each row typically represents one record, such as one employee, while each column represents a field or variable describing that record.

Last Name First Name Department City Salary
Jones Maria Accounting Houston $70,000
Mitchell Patricia Sales Las Vegas $85,000

1. Single Sort

A single sort organizes the entire list using the values in one selected field.

Sorting Text

Text fields can be sorted alphabetically:

  • A to Z arranges text in ascending alphabetical order.
  • Z to A arranges text in descending alphabetical order.

For example, selecting a cell in the Last Name column and sorting A to Z organizes the employee list alphabetically by last name.

Sorting by Another Field

The same approach can be used with fields such as Department. Selecting a cell in the Department column and sorting A to Z groups departments alphabetically.

Sorting Numbers

Numerical fields use equivalent ascending and descending options:

  • Smallest to Largest
  • Largest to Smallest
Example
Sorting the Salary field from largest to smallest places the employee with the highest salary at the top of the list and the employee with the lowest salary at the bottom.

Perform a Single Sort

  1. Select a cell in the field you want to use for sorting.
  2. Go to the Home tab.
  3. Select Sort & Filter.
  4. Choose the appropriate ascending or descending option.
The Entire Record Must Stay Together
Sorting should reorganize complete records. An employee's name, department, city, and salary should remain on the same row after the sort.

2. Multi-Level Sort

A multi-level sort organizes data using more than one field. One field establishes the primary grouping, and additional fields determine how records are ordered within those groups.

Example: Department and Salary

Suppose you want employees grouped by Department and, within each department, sorted from highest salary to lowest salary.

The sorting logic is:

Sort Level Field Order
1 Department A to Z
2 Salary Largest to Smallest

The result keeps all employees from the same department together, then ranks salaries within each department.

Create a Multi-Level Sort

  1. Select a cell somewhere inside the dataset.
  2. Open Sort & Filter.
  3. Select Custom Sort.
  4. Choose the primary field and its sort order.
  5. Select Add Level.
  6. Choose the second field and its sort order.
  7. Select OK.
Why multi-level sorts are useful: They allow managers to organize records into meaningful groups while still ranking or arranging records within each group.

4. Find Duplicates with Conditional Formatting

Duplicate records are difficult to identify visually when a dataset contains many rows. Conditional formatting can help locate repeated values.

Highlight Duplicate Values

  1. Select the cells you want to evaluate for duplicates.
  2. Go to Home > Conditional Formatting.
  3. Select Highlight Cells Rules.
  4. Select Duplicate Values.
  5. Choose a formatting option, such as a red highlight.

Duplicate Values Do Not Always Mean Duplicate Records

A repeated last name does not necessarily mean that the same employee appears twice. Two different employees may share a common surname.

Example
Maria Jones and Paul Jones share the same last name, but they represent two different employees. A repeated combination such as Patricia Mitchell appearing twice with the same department, city, and salary is a stronger indication of a duplicate record.
Review the Full Record
Conditional formatting identifies repeated values. Use the other fields in the record to determine whether the repetition represents an actual duplicate.

5. Removing Duplicates

After identifying a true duplicate, Excel can remove repeated records with the Remove Duplicates command.

Remove Duplicate Records

  1. Select a cell somewhere inside the dataset.
  2. Go to the Data tab.
  3. Select Remove Duplicates.
  4. Confirm whether the list has headers.
  5. Choose the fields Excel should use to identify duplicate records.
  6. Select OK.

Excel reports how many duplicate values were removed and how many unique values remain.

Before Removing Duplicates
Make sure repeated records are actually errors. Similar names or repeated values in one field do not necessarily mean that an entire record is duplicated.

6. DSUM()

The DSUM function adds values in a database field only for records that meet specified criteria.

DSUM Syntax

=DSUM(database, field, criteria)
Argument Meaning
database The complete data range, including the field names.
field The column containing the values you want to sum.
criteria A separate range containing field names and the conditions records must meet.

Specifying the Field

The field can be identified by its name in quotation marks or by its numerical position within the database.

=DSUM(database,"Salary",criteria)

or, if Salary is the fifth field:

=DSUM(database,5,criteria)

Using a Criteria Range

A criteria area repeats the relevant field names and places the desired conditions directly beneath them.

Department City Salary
Houston

With City set to Houston, DSUM returns the combined salary for employees whose records meet that criterion.

Other Criteria
The criteria can be changed to evaluate records for a different city, a department such as Human Resources, or another condition represented in the database.

7. DAVERAGE()

The DAVERAGE function calculates the average of values in a database field for records that meet specified criteria.

DAVERAGE Syntax

=DAVERAGE(database, field, criteria)

Like DSUM, DAVERAGE requires a database range, the field to analyze, and a criteria range.

Example
If Salary is the fifth field, a formula could use:
=DAVERAGE(database,5,criteria)
If the criteria specify Atlanta, the result is the average salary for the records that meet the Atlanta criterion.

Criteria Can Be Changed Without Rewriting the Formula

Because the formula refers to a criteria range, changing the value in that range can update DSUM, DAVERAGE, and other database functions at the same time.

Database-query approach: Database functions allow you to build a small analysis area in which the criteria can be changed to answer different questions from the same dataset.

8. DCOUNT()

The DCOUNT function counts numerical records in a selected database field that meet the specified criteria.

DCOUNT Syntax

=DCOUNT(database, field, criteria)
Example: Salary Greater Than $50,000
A Salary criterion can be written as:
>50000
DCOUNT then returns the number of salary records that meet the condition.

Using Multiple Criteria

More than one condition can be included in the criteria area. For example, the database can be queried for employees who:

  • work in Houston, and
  • have a salary greater than $60,000.
City Salary
Houston >60000

DSUM, DAVERAGE, and DCOUNT can all use the same criteria area to return different summaries of the records that meet those conditions.

9. SUBTOTAL()

The SUBTOTAL function performs a summary calculation on a range and is particularly useful when the dataset is filtered.

SUBTOTAL Syntax

=SUBTOTAL(function_num, ref1)

The first argument tells Excel which calculation to perform. The second argument identifies the range to summarize.

Function Numbers Used in This Module

Function Number Calculation Example
1 AVERAGE =SUBTOTAL(1,E2:E19)
4 MAX =SUBTOTAL(4,E2:E19)
9 SUM =SUBTOTAL(9,E2:E19)

Using SUBTOTAL with Filters

Filtering allows you to display selected records while excluding other records from the current view. SUBTOTAL can then summarize the visible records.

  1. Select a cell inside the dataset.
  2. Go to the Data tab.
  3. Turn on Filter.
  4. Use the drop-down controls in the field headers to select records.
  5. Review the SUBTOTAL result for the filtered data.
Example
If the City filter is set to Houston, a salary SUBTOTAL can display the sum or average for the Houston records. Changing the filter to Las Vegas or Atlanta updates the result.

Filtering by More Than One Field

Filters can be combined. For example, you can display only employees who work in a particular city and department, then use SUBTOTAL to summarize the visible salary values.

Keep the Summary Visible
Place SUBTOTAL calculations outside or below the main list so the summary remains easy to see while different filters are applied.
Why SUBTOTAL is powerful: It combines filtering with common calculations such as SUM, AVERAGE, and MAX, allowing you to quickly drill down into different portions of a dataset.

  • Distinguish repeated values from true duplicate records.

  • Explain the database, field, and criteria arguments used by database functions.
